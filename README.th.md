# ตัวแปลงข้อมูล 中国观鸟记录中心 → eBird

[中文](README.md) | [English](README.en.md) | **ไทย**

แปลงไฟล์ Excel ที่ export จาก [中国观鸟记录中心](https://www.birdreport.cn/) (birdreport.cn) เป็นไฟล์ CSV ที่ import เข้า eBird ได้ทันที (eBird Record Format, Extended) ใช้ย้ายบันทึกดูนกในจีนไปไว้ใน eBird

**ใช้งานออนไลน์: https://songpon123.github.io/birdreport-to-ebird/** (หน้าเว็บเป็นภาษาจีน)

![หน้าตัวแปลง: ขั้นตรวจสถานที่ก่อนดาวน์โหลด](docs/screenshot.jpg)

## ทำอะไรได้บ้าง

- **รองรับบันทึก 2 แบบ:** 定点记 (นับนกที่จุดเดียว) และ 随手记 (บันทึกที่เจอระหว่างทาง) ใส่ไฟล์ Excel ได้หลายไฟล์พร้อมกัน และแยกประเภทให้เอง
- **แก้พิกัดให้ถูก:** birdreport.cn เก็บพิกัดระบบ Baidu (BD-09) กับระบบ "火星" (GCJ-02) ตัวแปลงจะแปลงเป็นพิกัด GPS (WGS-84) ที่ eBird ใช้ ถ้าไม่แปลง จุดแถวปักกิ่งจะคลาดไปกว่า 500 เมตร
- **เติมพิกัดให้ 定点记:** ไฟล์ export ของ 定点记 ไม่มีพิกัด ถ้าอัปโหลดรายการจุดสังเกตจากหน้า 观测点管理 ไปด้วย ตัวแปลงจะเติมพิกัดให้
- **ชื่อนกตาม eBird 2026:** birdreport.cn ใช้อนุกรมวิธานจีน (郑光美 ฉบับที่ 4) ซึ่งชื่อวิทยาศาสตร์หลายตัวต่างจาก eBird 2026 เช่น 栗鹀 *Emberiza rutila* → *Schoeniclus rutilus* ตัวแปลงเปลี่ยนชื่อให้ 1,523 จาก 1,524 ชนิด eBird จึงไม่ขึ้นว่า "ไม่รู้จักชนิดนก"
- **กันข้อมูลซ้ำ:** เลือกช่วงวันที่ได้ ข้ามวันที่เคยลง eBird ไว้แล้ว และมีปุ่มลอง import แค่วันแรกก่อน
- **แบ่งไฟล์ให้เอง:** eBird รับไฟล์ import ได้ไม่เกิน 1 MB ถ้าเกิน ตัวแปลงจะแบ่งเป็นหลายไฟล์ และไม่ตัด checklist ไหนแยกข้ามไฟล์
- **จับคู่ hotspot ของ eBird (ไม่บังคับ):** ใส่ eBird API key ของตัวเอง แล้วสถานที่จะถูกจับคู่กับ hotspot ให้
- **ไม่แต่งจำนวนนก:** จำนวนที่ว่างหรือเป็น 0 จะใส่เป็น `X` (พบ แต่ไม่ได้นับ) และเลือกได้ว่าจะเปลี่ยน checklist ที่ทุกชนิดเป็น 1 ให้เป็น `X` ด้วยไหม
- **ไม่อัปโหลดข้อมูล:** ประมวลผลในเบราว์เซอร์ของเราเองทั้งหมด มีแค่ตอนจับคู่ hotspot ที่ดาวน์โหลดรายการ hotspot รายมณฑลจาก eBird

## วิธีใช้

1. **Export จาก birdreport.cn** (ใช้คอมพิวเตอร์): 用户中心 → 记录管理 → 报告查询 → 定点记 แล้วตามด้วย 随手记 **ไม่ต้องติ๊กเลือกรายการ** กดไอคอน export มุมขวาบนของตาราง → 导出到 Excel 文件 ถ้าได้ไม่ครบ ให้ยกเลิกการติ๊กทั้งหมดแล้ว export ใหม่ หรือตั้ง 200 รายการต่อหน้า เลือกทั้งหมด แล้ว export ทีละหน้า
2. **(แนะนำ) Export จุดสังเกต:** 记录管理 → 观测点管理 → ไอคอน export
3. **อัปโหลด:** ลากไฟล์ Excel ทั้งหมดใส่[หน้าตัวแปลง](https://songpon123.github.io/birdreport-to-ebird/)
4. **ตั้งค่า:** เลือกช่วงวันที่ และดูให้ "鸟名写法" (ภาษาชื่อนก) ตรงกับภาษาที่หน้าเว็บ eBird แสดงตอนเรา import (ดูหัวข้อถัดไป) ถ้ามี eBird API key ใส่เพื่อจับคู่ hotspot ได้
5. **ตรวจสถานที่ แล้วดาวน์โหลด CSV**
6. **Import เข้า eBird:** ใช้เบราว์เซอร์บนคอมพิวเตอร์ (แอป eBird ไม่มีเมนู import) ไปที่ Submit → Import Data เลือก **eBird Record Format (Extended)** แล้วอัปโหลด จากนั้นเข้า Manage Imported Data แก้สถานที่ (Fix Locations) และชื่อชนิด (Fix Species) แล้วกด Apply Fixes

## ข้อควรรู้ตอน import เข้า eBird

- **ภาษาชื่อนกต้องตรงกับภาษาหน้าเว็บ eBird:** ทดสอบเมื่อ 17 พ.ย. 2026 แล้วพบว่า eBird จับคู่ชนิดนกจากชื่อสามัญ ชื่อวิทยาศาสตร์ถูกต้องก็ช่วยไม่ได้ ถ้าหน้า eBird เป็นภาษาจีน ให้ใช้ชื่อจีน ถ้าเป็นภาษาอังกฤษ ให้ใช้ชื่ออังกฤษ ตัวแปลงจะเลือกให้ตามภาษาของเบราว์เซอร์ และเปลี่ยนเองได้ในขั้น 3
- **อย่า import วันที่เคยลง eBird แล้ว** ไม่อย่างนั้น checklist จะซ้ำกัน เช็กได้ที่ [My Checklists](https://ebird.org/mychecklists)
- **ครั้งแรกให้ลอง import แค่วันเดียวก่อน**
- **ในหน้า Fix Species ถ้าขึ้นตัวเลือกสีเขียวแล้ว** ตรวจให้ถูกแล้วกด Apply Fixes ได้เลย มีข้อสังเกตเรื่อง 山斑鸠 (Oriental Turtle-Dove) ถึงชื่อจะตรงทุกตัวอักษร eBird ก็ยังขึ้นว่าไม่รู้จัก แล้วเสนอชนิดที่ถูกให้ กด Apply Fixes ก็ผ่าน
- **ถ้า import ผิด** ไปที่ [Manage Imported Data](https://ebird.org/import/status/all.htm) แล้วกด Delete import ระบบจะลบทุกรายการที่มาจากไฟล์นั้น จากนั้นแก้ไฟล์แล้ว import ใหม่

## จับคู่ชื่อนกอย่างไร

| วิธีจับคู่ | จำนวนชนิด | หมายเหตุ |
|---|---|---|
| ชื่อวิทยาศาสตร์ตรงกัน | 1,430 | |
| ชื่ออังกฤษตรงกัน | 69 | ชื่อวิทยาศาสตร์ต่างกันแต่ชื่ออังกฤษเหมือนกัน เช่น 栗鹀 → *Schoeniclus rutilus* |
| คำระบุชนิด (epithet) ตรงกัน | 10 | เช่น 赤腹鹰 → *Tachyspiza soloensis* ในหน้าเว็บจะมีป้าย 请确认 (โปรดตรวจ) |
| กลุ่มชนิดย่อย / ถูกรวมเข้ากับชนิดอื่น | 14 | eBird ไม่ได้นับเป็นชนิดแยก จับคู่ด้วยมือทีละตัว เช่น 华西柳莺 → *Phylloscopus affinis occisinensis* ดูได้ที่ [`taxonomy/groups.json`](taxonomy/groups.json) |
| ไม่มีคู่ | 1 | 环江鹪鹛 (eBird ยังไม่มีชนิดนี้) ต้องเลือกเองตอน import |

## สำหรับนักพัฒนา

ดูโครงสร้างไฟล์และคำสั่ง build ได้ในหัวข้อ "开发" ของ [README ภาษาจีน](README.md#开发) หรือ "Development" ของ [README ภาษาอังกฤษ](README.en.md#development) สรุปสั้นๆ:

- แก้ `src/app.html` แล้วรัน `python3 build.py` จะได้ `index.html` (ใช้บน GitHub Pages) และ `birdreport-to-ebird.html` (ไฟล์เดียว ใช้ออฟไลน์ได้)
- อัปเดตตารางชื่อนกด้วย `python3 taxonomy/build_name_table.py` แล้วรัน `python3 build.py`
