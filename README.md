# 观鸟记录中心 → eBird 转换器

把中国观鸟记录中心（birdreport.cn）导出的 Excel 转换成 eBird 可以直接导入的 CSV（eBird Record Format, Extended）。

**在线使用：https://songpon123.github.io/birdreport-to-ebird/**

**也可以下载这一个文件离线使用：`birdreport-to-ebird.html`。** 双击用浏览器打开就能用，不需要安装任何东西，也不需要联网（只有「匹配 eBird 热点」这一步要联网）。所有记录只在你自己的浏览器里处理，不会上传。

## 使用方法

1. 在 birdreport.cn 网页版：用户中心 → 记录管理 → 报告查询 → 定点记 / 随手记。**不勾选任何报告**，直接点表格右上角的导出图标 → 导出到 Excel 文件。
   - 网站的导出代码在没有勾选时会请求全部记录（`ids` 为空），所以应该一次就能导出全部。这一点还没有用真实账号验证过；如果数量不对，就改用「每页 200 条 → 全选 → 逐页导出」。
2. （推荐）记录管理 → 观测点管理，导出观测点列表（带百度坐标）。定点记的导出文件里没有坐标，有了这个文件就能补上。
3. 打开 `birdreport-to-ebird.html`，把这些文件一起拖进去（可以一次放多个文件）。
4. 选日期范围：**已经在 eBird 记过的日期不要再导入**，否则会产生重复清单。第一次可以点「试导入：只要最早的一天」。
5. （可选）填入自己的 eBird API Key，点「匹配热点」。Key 在 https://ebird.org/api/keygen 免费获取。
6. 检查地点，下载 CSV。eBird 每个导入文件最多 1 MB，超过时会自动按清单分成几个文件。
7. 在 https://ebird.org/import 上传，格式选 eBird Record Format (Extended)，然后在 Manage Imported Data 里修正地点（Fix Locations）和鸟种（Fix Species）。网页里有详细步骤。

## 记录中心导出文件的格式（来自网站自己的导出代码）

| 文件 | 列 | 坐标 |
|---|---|---|
| 定点记 `定点记报告记录导出.xlsx` | 报告编号、观测开始时间、观测结束时间、中文名、拉丁名、省、州/市、区/县、观测点名称、IUCN受胁级别、国家保护等级、CITES保护等级、鸟种数量 | 没有 |
| 随手记 `随手记报告记录导出.xlsx` | 报告编号、中文名、拉丁名、省、州/市、区/县、IUCN受胁级别、国家保护等级、CITES保护等级、经度（百度）、纬度（百度）、经度（火星）、纬度（火星）、鸟种数量、记录时间、描述 | 百度 BD-09（原始）和火星 GCJ-02（网站换算） |
| 观测点管理 | 省份、州/市、县/区、观测点名称、经度、纬度…… | 百度 BD-09 |

`tests/samples/` 里的测试文件按这些列生成，坐标由已知 GPS 点正向换算，转换回来的误差小于 0.2 米。

## 和其他转换工具相比改进了什么

| 问题 | 这里的做法 |
|---|---|
| 随手记的「火星坐标」(GCJ-02) 直接当 GPS 用，位置偏几百米 | 自动转换成 WGS-84（北京一带约偏 500 多米）；只有百度坐标时也能转换 |
| 定点记没有坐标，导入 eBird 时每个地点都要手动在地图上找 | 上传观测点列表后自动补上坐标 |
| 逐页导出很麻烦 | 不勾选任何报告直接导出（见上方说明） |
| 记录中心用郑光美第四版学名，eBird 2026 改了很多属名（如 Emberiza → Schoeniclus），导入时显示「未知鸟种」 | 写 eBird 2026 学名 + eBird 自己的鸟名。2026-11-17 实测：eBird 导入按鸟名识别鸟种，鸟名要和导入时 eBird 网页的语言一致（中文网页用 eBird 中文名，英文网页用英文名）。默认按浏览器语言自动选，也可以手动改。1,524 种中 1,509 种能自动对应；10 种按学名词尾对应，页面上标为「请确认」；15 种 eBird 没有单一对应种，导入时手动选 |
| 和 eBird 里已有的清单重复 | 可以只导出某段日期；有「试导入一天」按钮 |
| 记录多时超过 eBird 1 MB 的文件限制 | 自动按清单分成多个文件，同一份清单不会被拆开 |
| 数量为空或 0 时写成 1 | 写成 `X`，不编造数量；原数量为 0 会在备注里说明 |
| 随手记合并后标成「完整记录」 | 随手记一律是 Incidental、非完整记录 |
| 随手记 5 公里内都并到热点 | 匹配范围可选 200 米 – 2 公里，默认 500 米 |
| 省份代码和 eBird 不一致（如 `YN`） | 使用 eBird 的代码（如云南 `53`）；新疆两种写法都能识别 |
| 香港、澳门、台湾填成国家 `CN` | 按 eBird 的做法分别填 `HK`、`MO`、`TW` |
| 定点记缺少时间或结束早于开始时出错 | 自动改用 Historical，并在清单备注里写明原时间 |
| 地点列靠固定位置查找 | 先按列名查找，找不到才用「IUCN受胁级别」前一列 |
| 重复导出的同一条记录会被算两次 | 不同文件里完全相同的记录只保留一次 |
| 同一份清单里同一鸟种出现两次 | 合并成一行，数量相加 |
| 写着「不上传服务器」但实际运行在服务器上 | 真正在浏览器本地运行 |

## 怎么分享给别人

- **发网址**：https://songpon123.github.io/birdreport-to-ebird/ ，请在电脑浏览器里打开（微信内置浏览器不能下载文件）。
- **直接发文件**：如果网址打不开，把 `birdreport-to-ebird.html` 通过微信、QQ 发给别人，对方在电脑浏览器里打开即可，不需要联网。

## 开发

- 源文件：`src/app.html`；Excel 读取组件：`vendor/xlsx.full.min.js`（SheetJS 0.18.5，Apache-2.0）。
- 修改源文件后运行 `python3 build.py`，会把组件内联进 `birdreport-to-ebird.html` 和 `index.html`（GitHub Pages 用）。
- 测试用的假数据：`node tests/make_samples.js` 生成到 `tests/samples/`。
- 鸟名对照表：`taxonomy/cn_to_ebird_2026.json`（记录中心名录 → eBird 2026，按学名、英文名、学名词尾三步匹配，来自 Bird Finder 项目）。`python3 taxonomy/build_name_table.py` 会再从 eBird 取简体中文名，生成页面使用的 `taxonomy/name_table.json`，然后运行 `python3 build.py`。

## 更新记录

- **2026-11-17**：学名改用 eBird 2026 分类，鸟名改用 eBird 自己的写法。实测：中文 eBird 网页 + eBird 中文名可以识别；英文网页 + 中文名会显示「未知」，英文网页要用英文名。所以「鸟名写法」默认按浏览器语言选。修正鸟种页面出现绿色匹配时直接点「应用修正」；还有很多「未知」的旧导入，可以在「管理导入的数据」里删除（Delete import）后用新版重新导入。
- **2026-11-17**：增加日期范围和「试导入一天」、超过 1 MB 自动分文件、观测点坐标、百度坐标转换。
- **2026-11-16**：第一版。
