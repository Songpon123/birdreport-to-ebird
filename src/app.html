观鸟记录中心→eBird

把中国观鸟记录中心（birdreport.cn）导出的 Excel 转换成 eBird 可以直接导入的 CSV 文件。文件只在你的浏览器里处理，不会上传到任何服务器。

2026-11-17 更新：鸟名和学名改用 eBird 2026 的写法。 之前很多鸟种导入后显示「未知」（例如 栗鹀、灰头鹀、牛背鹭），是因为记录中心用的是旧分类的学名，现在已经换成 eBird 2026 的学名。另外实测发现：eBird 按鸟名识别鸟种，鸟名要和导入时 eBird 网页的语言一致（网页是中文就用中文名，英文就用英文名），在第 3 步「鸟名写法」里选。
  • 在 eBird「修正鸟种」页面，如果右边已经出现绿色的匹配，直接点应用修正即可。
  • 上次导入后还有很多鸟种显示「未知」：到 eBird 的管理导入的数据（Manage Imported Data），点那次导入的 Delete import 删除，再用这个新版本重新转换、重新导入。已经手动修正好的不需要重做。

1从观鸟记录中心导出 Excel

  1. 用电脑浏览器打开 birdreport.cn 网页版并登录，点右上角的昵称进入用户中心。
  2. 左侧点记录管理 → 报告查询，打开定点记。
  3. 不要勾选任何报告，直接点表格右上角的导出图标 →导出到 Excel 文件。不勾选时，网站应该会导出你的全部定点记，不用一页一页导。
  4. 再打开随手记，用同样的方法导出。
  5. （推荐）左侧点记录管理 → 观测点管理，用表格右上角的导出图标导出观测点列表（带经纬度）。一起上传后，定点记也会带上坐标，导入 eBird 时就不用在地图上一个个找位置。观测点多的话，每页导出一次。

如果导出的报告数量比网站上少，可能是之前勾选过的报告还记着。取消所有勾选后再导出；或者把每页改为 200 条，全选，逐页导出。

4检查地点

这一步要做什么
  • eBird 热点 会直接使用这个热点。导入时 eBird 通常会自动对上，确认即可。
  • 自定义地点（有坐标） 会用记录里的坐标建立你自己的地点。导入时 eBird 按坐标定位，确认即可。
  • 导入时需在地图上点选 记录里没有坐标。可以回到第 2 步，上传「观测点管理」导出的文件来补上；否则导入时要在 eBird 地图上找到位置点一下。
  • 匹配过热点后，最右边一列可以改选别的热点，或选「不用热点」。出现「有几个名字相近的热点，请确认」时，请打开下拉菜单选对的那个。
  • 不想改的话可以跳过这一步，直接下载。

怎么导入 eBird（第一次请先看完）
  1. 确认不会重复：所选日期内的观鸟，eBird 里还没有（见第 3 步）。第一次建议先用「试导入：只要最早的一天」。
  2. 用电脑浏览器登录 eBird：不要用 eBird 手机 App，App 里没有导入功能。注意 eBird 网页显示的语言要和第 3 步「鸟名写法」一致（都用中文，或都用英文）。
  3. 上传文件：在 eBird 网站顶部点 Submit（提交）→Import Data（导入数据），或直接打开ebird.org/import。格式选 eBird Record Format (Extended)，选择刚下载的 CSV，点 Import File。eBird 每个文件最多 1 MB，本工具已经自动分好；有几个文件就上传几次。
  4. 等待处理：文件格式正确时会显示正在处理；有问题时 eBird 会列出格式错误。
  5. 修正地点（Fix Locations）：到我的 eBird → 管理导入的数据（Manage Imported Data）打开这次导入。每个地点可以选 eBird 热点、选以前用过的地点（Your Locations），或用 Find it on a Map 在地图上点选。改完点 Apply Fixes 保存。
  6. 修正鸟种（Fix Species）：本工具已经把鸟名换成 eBird 2026 的名称，大部分会自动对上。剩下的如果右边已经出现绿色的匹配，确认后直接点 Apply Fixes（应用修正）；没有匹配的（见上面「鸟种名称对照」里标为「需手动选择」的）点 Choose Species 选对应的鸟种，再点 Apply Fixes。原鸽请选 Rock Pigeon (Feral Pigeon)。
  7. 检查结果：到「我的 eBird」看看清单的日期、地点和数量对不对。
  8. 导错了怎么办：在「管理导入的数据」里点这次导入的 Delete import，会删除这个文件导入的全部记录；改好后重新导入即可。只有个别清单有问题时，直接在 eBird 里编辑那份清单。
非官方工具，与中国观鸟记录中心、eBird 及康奈尔鸟类学实验室无关。 记录中心的百度坐标（BD-09）和火星坐标（GCJ-02）都会自动转换成 eBird 使用的 GPS 坐标（WGS-84）。
